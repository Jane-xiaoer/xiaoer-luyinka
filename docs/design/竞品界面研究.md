> 用途：给「小耳录音卡」（Mac + 安卓 App）做界面设计参考

## 1. Plaud（Note / NotePin + App / Web / Desktop）

背景：2025-10-09 发布 Intelligence 3.0 / App 3.0，移动端和 Web 统一新设计 【官方】[Plaud App 3 设计](https://www.plaud.ai/blogs/news/plaud-app-3-design-intelligence)；Plaud Desktop（Beta）可无 bot 录 Zoom/Meet/Teams，笔记在 App 与 Web 间同步 【官方】[Release notes](https://www.plaud.ai/pages/plaud-release-notes)。

**1) 首屏**
- 首屏是**文件列表（files page）**，右上角放大镜进入搜索 / 「Ask Plaud Anything」。【官方】[Ask Across All Files](https://support.plaud.ai/hc/en-us/articles/50810294218137)
- 底部有 **Explore** Tab（AutoFlow、Integrations 都在里面）。【官方】[Automatic transcription](https://support.plaud.ai/hc/en-us/articles/62437655066649)、[Zapier integration](https://support.plaud.ai/hc/en-us/articles/12200669941647)
- 2026-06 起新用户默认开启 AutoFlow：录音同步上云后自动转写+摘要，不用手动点 Generate（>200 词才自动跑）。【官方】[Automatic transcription](https://support.plaud.ai/hc/en-us/articles/62437655066649)

**2) 详情页**
- 顶部是 **Summary / Notepad** 等 Tab，旁边一个 **「+」可以再加一个"维度"的摘要**（意图分析、关键数据……），每个新摘要是独立 Tab，原摘要不被覆盖。【官方】[Multidimensional summaries](https://support.plaud.ai/hc/en-us/articles/50636073405081)
- 内容类型：音频、逐字稿、AI 摘要、思维导图（导图可导出 PNG/Markdown，不能再编辑）。【官方】[Export](https://support.plaud.ai/hc/en-us/articles/50835453223705)
- 播放器：Web 端内置，6 档倍速（0.75–2×），±15 秒；**点逐字稿任意一行跳到对应音频，播放器与逐字稿同步滚动**。【官方】[Playback audios](https://support.plaud.ai/hc/en-us/articles/51899816130713)
- 说话人：自动区分，可命名；2026-05 支持用「查找替换」批量改说话人名。【官方】[Release notes](https://www.plaud.ai/pages/plaud-release-notes)
- 2026-07 新增 Auto Polish 自动润色逐字稿，**原始稿"一键可回看"**。【官方】同上

**3) 问 AI**
- **单文件**：摘要页**底部「ASK」输入框** + 快捷按钮（Summarize / Get Insights / Generate To-Dos / Write Email）；回答里带**可点击时间戳 [00:15:30]** 跳回原文；给 3–5 个追问建议；**一键把回答存成该文件的一个摘要 Tab**。【官方】[Ask Based on a Single File](https://support.plaud.ai/hc/en-us/articles/51893290412313)
- **全库**：列表页右上放大镜 → Ask Plaud Anything，回答附来源录音。【官方】[Ask Across All Files](https://support.plaud.ai/hc/en-us/articles/50810294218137)
- 2026-10 拆成 **Chat（问答，免费）/ Work（Agent 干活，耗 credits）** 两模式，每次对话开始前选，默认 Chat；Work 可出 PDF/PPT/Word，经 Connectors 发到 Slack/Notion/Linear。【官方】[Ask Plaud: Chat & Work](https://www.plaud.ai/blogs/news/ask-plaud-chat-work)
- 回答的视觉：「干净、带来源链接、用克制的功能色高亮」。【官方】[Plaud App 3 设计](https://www.plaud.ai/blogs/news/plaud-app-3-design-intelligence)

**4) 导出 / 给 agent**
- 文件右上角图标 → Export as file：音频 MP3/WAV、逐字稿 TXT/SRT/DOCX/PDF（可勾选时间戳、说话人）、摘要 TXT/Markdown/DOCX/PDF。【官方】[Export](https://support.plaud.ai/hc/en-us/articles/50835453223705)
- **官方 MCP**：Claude（Connector Directory 一键）、ChatGPT（Plugins Directory 一键），Cursor/Windsurf/Zed/Gemini CLI 走终端；能力 = 列最近录音、搜索、取逐字稿、取摘要和待办。【官方】[Plaud MCP](https://support.plaud.ai/hc/en-us/articles/57751078986265)、[MCP & CLI 发布（2026-09-22）](https://uk.plaud.ai/blogs/news/introducing-plaud-mcp-and-cli)
- Zapier：Plaud Web → Explore → Integrations，触发器 = 「转写生成」「摘要生成」。【官方】[Zapier integration](https://support.plaud.ai/hc/en-us/articles/12200669941647)
- 分享：Trusted Sharing 可选分享音频/逐字稿/摘要/高亮，控制谁能看、链接有效期。【官方】[Release notes](https://www.plaud.ai/pages/plaud-release-notes)

**5) 硬件 / 同步**
- 设备连上 App 后**蓝牙自动传，不用点**；大文件时**右上角弹出 Fast Transfer 提示**，切 Wi-Fi，传完自动切回蓝牙并回主屏。【官方】[Transfer files](https://support.plaud.ai/hc/en-us/articles/50828234295577)
- 电量：设备列表里设备旁的**电池图标**，或设备设置页的电量说明；需显示 Connected 才看得到。【官方】[NotePin S 电量](https://support.plaud.ai/hc/en-us/articles/53693784567449)
- 2026-04 加低电量通知；Note Pro / NotePin S 设备页显示**预计剩余可录时长**。【官方】[Release notes](https://www.plaud.ai/pages/plaud-release-notes)
- 传输进度条的具体样式：【未查实】

**6) 视觉风格**
- 关键词：**和硬件一样精致、极简、大留白（自称 70–80% 留白）、功能色只用在 AI 交互和会员功能、从概览到细节的层级**。【官方】[Plaud App 3 设计](https://www.plaud.ai/blogs/news/plaud-app-3-design-intelligence)

## 2. 飞书妙记（含 安克 × 飞书 AI 录音豆）

**1) 首屏**
- 「飞书妙记首页」= 文件列表；桌面端右上角「上传」，可直接把音视频拖进首页；**新上传文件出现在列表最顶端，列表里直接显示"处理中/转写中"进度**；右下角上传小窗显示每个文件的上传进度和速度。手机端右下角「麦克风」开始录音。【官方】[飞书妙记介绍（2025-12）](https://www.feishu.cn/content/article/7578773484596153570)

**2) 详情页**
- **左侧视频/播放器，右侧文字记录**；**点文字里任意字词即跳到对应音视频位置**；视频下方有**发言人时间轴**，点它定位到某人的发言。【官方】同上
- 「智能纪要」Tab：总结、智能章节、关键决策、金句时刻、待办；右上「设置」可加自定义提炼维度（如客户需求、风险点）。【官方】同上；【评测】[爱范儿 AI 录音豆（2026-01）](https://www.ifanr.com/1652210)
- 智能纪要会按内容自动插入**表格、时间线、图表**；还能生成一张可编辑的「总结画板」（像一页 PPT）。【评测】[爱范儿](https://www.ifanr.com/1652210)
- **零等待尾窗**：按结束录音，App 立刻弹出速览（总结 / 待办 / 观点摘录），完整纪要后到。【评测】同上
- 会中有实时总结（鱼骨图 / 文字两版）。【评测】同上

**3) 问 AI**
- 单篇「妙记问答」（如直接按面试回答输出面评）；跨多条记录也可问。【官方】[飞书妙记介绍](https://www.feishu.cn/content/article/7578773484596153570)
- 「知识问答」能同时检索录音纪要 + 全部飞书文档。【评测】[爱范儿](https://www.ifanr.com/1652210)
- 问答框具体长相：【未查实】

**4) 导出 / 给 agent**
- 搜索框右侧「···」→「导出文字记录」：飞书文档 / TXT / SRT，可选是否含说话人、时间戳。【官方】[飞书妙记介绍](https://www.feishu.cn/content/article/7578773484596153570)
- 一键分享（先定"谁能看"再定"看什么"），可截取片段分享；待办同步飞书任务，纪要推送群聊。【官方】同上
- 纪要可导出 Word / PDF。【评测】[爱范儿](https://www.ifanr.com/1652210)
- agent 侧：飞书官方（larksuite）有 `lark-minutes` agent skill，可取 总结 / 章节 / 待办 / 关键词 / 逐字稿。【第三方目录】[lark-minutes](https://mcpservers.org/fr/agent-skills/larksuite/lark-minutes)

**5) 硬件 / 同步**
- 录音豆脱离手机也能录，连手机后会中可看实时转写与 AI 总结，会后自动同步到飞书生成纪要。【评测】[爱范儿](https://www.ifanr.com/1652210)
- **妙记页面会显示已连接设备以及正在处理的文件**（截图说明）。【评测】同上
- 电量显示：【未查实】

**6) 视觉风格**
- 飞书体系：白底、蓝色强调、信息密度中高；纪要里大量用彩色分区高亮、图表。【评测，风格判断为推断】[爱范儿](https://www.ifanr.com/1652210)

## 3. Limitless（Pendant App）

> ⚠️ 2025-12-05 被 Meta 收购，停止向新用户卖 Pendant，老用户支持到 2026 年底，欧盟/英国/中国等地区停服。只当设计参考，不是活跃竞品。【官方】[limitless.ai](https://limitless.ai/)；【评测】[9to5Mac](https://9to5mac.com/2025/12/05/rewind-limitless-meta-acquisition/)

**1) 首屏**
- **Lifelog 视图**：按天浏览，顶部「Today」点开选日期（有记录的日期显示为黑色）；底部 Tab 有「Ask」和「Settings」。录音几分钟后就出现第一段 Lifelog。【官方】[Interacting with the Pendant](https://help.limitless.ai/en/articles/10546658-interacting-with-the-pendant-app-search-ask-ai-summaries)、[Quick-Start](https://help.limitless.ai/en/articles/10619382-pendant-quick-start-guide)

**2) 一天的详情**
- 一天 = 自动切分的若干「段」，每段一个标题 + 摘要；**点摘要标题左边的小箭头展开逐字稿**。【官方】[Interacting with the Pendant](https://help.limitless.ai/en/articles/10546658-interacting-with-the-pendant-app-search-ask-ai-summaries)
- 每段左侧有**复选框**：勾选后底部出现 Play / Copy / Star / Share / 下载音频——**播放器不是常驻的，而是"选中段落→播放"**。【官方】同上
- 长按任意文字 2 秒进入编辑；改说话人时问「全部替换还是只改这行」。【官方】同上
- 硬件按一下 = **星标当前时刻**，回 App 可找。【官方】[Quick-Start](https://help.limitless.ai/en/articles/10619382-pendant-quick-start-guide)

**3) 问 AI**
- 底部 Tab「Ask」→ 输入框占位文字「Ask about anything you've said or heard」；左上 ☰ 看历史对话。【官方】[Interacting with the Pendant](https://help.limitless.ai/en/articles/10546658-interacting-with-the-pendant-app-search-ask-ai-summaries)
- **答案底部「Ask daily」**：把这个问题变成每天定时推送（自定义每日通知）。【官方】同上
- 2025 年陆续加了 Daily Insights、提醒、Gmail/日历接入、「Roast my last week」类人格提示。【评测汇总】[feedback.limitless.ai 公告](https://feedback.limitless.ai/announcements)（页面需登录，内容经搜索摘要转述）

**4) 导出 / 给 agent**
- 勾选段落 → Copy，可勾/不勾摘要或逐字稿，选 3 种格式之一复制到剪贴板；桌面端每段有「Copy Markdown」。【官方】[Interacting with the Pendant](https://help.limitless.ai/en/articles/10546658-interacting-with-the-pendant-app-search-ask-ai-summaries)
- 分享链接（逐字稿 / Ask 对话都能分享，不支持分享音频）。【官方】同上
- 官方 API（仅 Pendant 数据）；2025-10 上线「如何连接 ChatGPT / Claude / Cursor」指南；MCP 多为社区实现。【官方】[Limitless API](https://help.limitless.ai/en/articles/11106060-limitless-api)；【第三方】[mcp-limitless-server](https://glama.ai/mcp/servers/fz845ppefp)

**5) 硬件 / 同步**
- **打开 App 才同步**；内存满时设备红灯 10 连闪，提示"打开 App 同步完再录"。【官方】[LED 说明](https://help.limitless.ai/en/articles/10542073-what-do-the-different-pendant-led-light-colors-mean)
- 2025-09 的 1.0.43 版加了低电量指示器。【评测汇总】[feedback 公告](https://feedback.limitless.ai/announcements)
- 用户抱怨：App 里看不出设备是否在充电，只能等电量数字涨。【第三方反馈】[Omi featurebase](https://omi.featurebase.app/p/show-charging-status-for-limitless-pendant-in-the-omi-app)

**6) 视觉风格**：【未查实】（没找到可靠描述，不臆测）

## 4. Otter.ai

**1) 首屏**
- Home（Homepage）：会议列表 + 日历日程；AI Chat 在 Home / 会议页 / Channel **用同一种方式唤起**。【官方】[Otter AI Chat Overview](https://help.otter.ai/hc/en-us/articles/19682180167575)
- 早年改版就以"一周会议一屏可见"的 Home feed 为核心。【评测】[mytechdecisions](https://mytechdecisions.com/unified-communications/new-otter-features/)

**2) 详情页（Conversation page）**
- 两个 Tab：**Summary**（摘要 + AI 待办 + Outline）/ **Transcript**（看逐字稿与回放）；**右侧面板**按 Tab 切换显示 Otter Chat / Outline / Comments。【官方】[新会议页布局](https://help.otter.ai/hc/en-us/articles/21695002816535)、[Conversation Page Overview](https://help.otter.ai/hc/en-us/articles/5093228433687)
- **AI 生成的待办有「View in transcript」图标，点了跳到出处**；手动加的没有。待办会自动指派给参会人（悬停头像看是谁）。【官方】[Conversation Page Overview](https://help.otter.ai/hc/en-us/articles/5093228433687)
- 高亮集中在 Transcript Tab，「Show only highlights」只看高亮；可在逐字稿上划词评论、@人、加表情。【官方】[Interact with your transcript](https://help.otter.ai/hc/en-us/articles/360048464113)
- 坑：**改了说话人后摘要不能重新生成**，官方建议用 Chat 重新生成。【官方】[Conversation Page Overview](https://help.otter.ai/hc/en-us/articles/5093228433687)

**3) 问 AI**
- AI Chat，**Chat / Work 双模式**：Chat 问答/分析；Work 执行任务（建 Jira、写 Notion、发 Gmail 草稿、生成 PPT/Word），需要权限时弹「Permission needed」让你 Allow/Deny。默认私有，可选择分享。上下文可加会议、Channel、文件夹、连接的 App。【官方】[Otter AI Chat Overview](https://help.otter.ai/hc/en-us/articles/19682180167575)

**4) 导出 / 给 agent**
- 会议页右上「···」→ Export：剪贴板 / TXT / DOCX / PDF / SRT / MP3，可勾选说话人、时间戳、高亮、合并段落，**下方有导出预览**。待办和大纲不能单独导出。【官方】[Export conversations](https://help.otter.ai/hc/en-us/articles/360047733634)
- **官方 MCP Server**：Claude（Settings → Connectors）、ChatGPT（App Store）、Cursor、Perplexity；OAuth 授权。【官方】[Otter MCP Server](https://help.otter.ai/hc/en-us/articles/35287607569687)
- 分享：Collaborator / Viewer 两级权限，公开链接默认只读。【官方】[Share a conversation](https://help.otter.ai/hc/en-us/articles/360048338793)

**5) 硬件 / 同步**：无自有硬件。桌面端有"暂停/结束录音指示器"、自动录音、自动结束。【官方】[Otter Desktop App](https://help.otter.ai/hc/en-us/articles/35973988280215)

**6) 视觉风格**：协作工具型，Tab + 右侧面板 + 评论/表情/指派，**信息密度高**（由文档结构推断，非官方描述）。

## 5. Bee（2025-07 被 Amazon 收购）

## 7. Granola（桌面会议笔记，界面口碑最好）

**1) 首屏**
- 「Coming up」（日历里接下来的会议，点一下就建好这场会的笔记）+「Your notes」（按天分组的列表行：标题、时间、参会人，超 2 人折叠为 +N）；左栏 Spaces（私有 My notes / 团队空间）+ 文件夹。**没有引导轮播，填满的列表本身就是引导。**【官方】[Granola 101](https://docs.granola.ai/article/granola-101)；【第三方拆解】[Granola UX Reference](https://cdn.jsdelivr.net/npm/@agent-native/core@0.124.6/corpus/templates/clips/desktop/design-refs/granola-ux.md)

**2) 详情页**
- **就是一页记事本**：你自己打的字是**黑色**，AI 补充的是**灰色**；你一改灰字它就变黑（所有权可见）。【官方】[编辑增强笔记](https://www.granola.ai/docs/docs/101/afteryourmeeting/editing-your-enhanced-notes)
- 每条 AI 要点旁有**放大镜**，点开看它依据的原话（溯源）。【官方】[AI-enhanced notes](https://docs.granola.ai/help-center/taking-notes/ai-enhanced-notes.md)
- 右上「✨」换模板（1:1 / Stand-up / 面试…），「🔁」用当前模板重生成。【官方】同上
- 逐字稿不是主角：从录音药丸展开，**聊天气泡式**（灰=对方，绿=我）。【第三方拆解】[Granola UX Reference](https://cdn.jsdelivr.net/npm/@agent-native/core@0.124.6/corpus/templates/clips/desktop/design-refs/granola-ux.md)
- **不保存音频**，只存逐字稿和笔记 → 没有播放器。【官方】[安全与隐私](https://granola.ai/security)

**3) 问 AI**
- 屏幕**底部常驻 Chat 框**（Cmd/Ctrl+J）；**作用域跟着你在哪**：首页=全部笔记，会议页=这一场，文件夹=这个集合，也可勾选几场会议。输入 `/` 调出 Recipes（可复用提示词）。【官方】[Ask Granola](https://docs.granola.ai/article/chatting-with-your-meetings-ask-granola)；【评测】[Zapier 测评](https://www.zapier.com/blog/granola-ai)
- 文件夹 Chat 的答案带**内联引用，可跳回出处**。【官方】[Granola 2.0](https://www.granola.ai/blog/two-dot-zero)

**4) 导出 / 给 agent**
- 右上 Share；分享链接给没账号的人也能看（只看摘要不看逐字稿），还能在链接里和 AI 聊。【官方】[Granola 2.0](https://www.granola.ai/blog/two-dot-zero)；【评测】[Zapier](https://www.zapier.com/blog/granola-ai)
- 会后**自动发 Slack**（含摘要、待办、「Chat with this meeting」按钮）；Notion、HubSpot、Zapier。【官方】[Granola 2.0](https://www.granola.ai/blog/two-dot-zero)
- **官方 MCP（2026-02-04）**：Claude Connectors / ChatGPT 设置里搜 Granola 一键 OAuth；Claude Code 一条命令 `https://mcp.granola.ai/mcp`。【官方】[Granola MCP](https://docs.granola.ai/help-center/sharing/integrations/mcp)；【第三方】[layer3labs 指南](https://www.layer3labs.io/guides/granola-mcp)

**5) 录音状态**（无硬件，但录音指示值得抄）
- 笔记页**底部中央一个"药丸"**，绿色竖条随声音跳；切到别的 App 时浮在屏幕右边缘可拖；会后/静音 15 分钟/睡眠自动停。【第三方拆解】[Granola UX Reference](https://cdn.jsdelivr.net/npm/@agent-native/core@0.124.6/corpus/templates/clips/desktop/design-refs/granola-ux.md)

**6) 视觉风格**
- **纸感、安静**：近白/暖米底、细边框不用重阴影；衬线标题（Quadrant）+ 无衬线正文（Melange）；橄榄绿/酸性绿点缀；中低密度、留白大。创始人说灵感来自 OXO 厨具，追求"忙碌日子里的平静"。【第三方拆解】[shadcn Granola 设计](https://www.shadcn.io/design/granola)、[Ragged Edge 品牌](https://www.abduzeedo.com/granola-brand-identity-design-ragged-edge)；【访谈】[Cognitive Revolution](https://www.cognitiverevolution.ai/calm-ai-for-crazy-days-inside-granola-s-design-philosophy-with-co-founder-sam-stephenson/)
- 反面评价：有人嫌「灰配灰」对比度太低。【评测】同上搜索结果

## 综合结论（≤400 字）

**首屏**：抄 Granola + Limitless——「今天」优先、按天分组的列表，每行只放标题、时长、一句话摘要；设备状态（连接/电量/同步中 N 条）压成顶部细状态栏，同步完自动收起。

**详情页**：抄 Plaud + 飞书——上摘要（要点/待办）下逐字稿，播放器常驻底部；**逐字稿任意一句可点跳音频**，AI 要点带溯源（Granola 放大镜 / Otter「View in transcript」）。一整天长录音用 Bee 的"按话题切段+彩色底"。

**问答**：抄 Granola——底部常驻输入框，作用域随页面（列表页=全部，详情页=这条）；答案带可点时间戳（Plaud），常用问题做成快捷按钮。

**导出给 agent**：抄 Bee/Plaud——一条命令或一键接 MCP，外加「复制为 Markdown」。

**坑**：功能只在手机端（Limitless）；不留音频没法核对（Bee/Granola）；改说话人摘要不更新（Otter）；Chat/Work 双模式难懂；灰配灰太淡。
